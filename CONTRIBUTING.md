# 🤝 Contributing to Movie Ticket Booking Management System

Thank you for your interest in contributing to this project!

## 📜 Code of Conduct
We are committed to providing a welcoming, inclusive, and harassment-free experience for everyone.

## 🛠️ Contribution Guidelines
1. **Fork the Repository**: Create your feature branch (`git checkout -b feature/AmazingFeature`).
2. **Adhere to Pega Best Practices**:
   - Utilize standard naming conventions (`Data-`, `Work-`).
   - Implement declarative rules wherever possible rather than procedural code.
   - Maintain SLA and Decision Table separation of concerns.
3. **Document Your Work**: Update corresponding documentation under `/docs` and include test verification.
4. **Commit & Push**: Commit changes with clear, descriptive messages and open a Pull Request.
